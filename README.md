# Johann dos Santos — Portfólio

Versão para publicação pública no Render. Site estático em HTML, CSS e JavaScript, sem dependências ou variáveis secretas.

Esta branch `johann-portfolio-render` contém o portfólio pessoal de Johann. A branch `main` deste repositório mantém o projeto Suyá Silva e sua publicação existente.

Render: nome `johann-dos-santos-portfolio`; branch `johann-portfolio-render`; build `node --check dist/app.js`; diretório público `dist`; `SKIP_INSTALL_DEPS=true`.

A imagem `dist/assets/suya-cover.webp` é o material original do projeto Suyá Silva. Os dois repositórios apresentados continuam privados e os links são identificados como exigindo acesso.
